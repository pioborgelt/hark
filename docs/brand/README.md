# Hark brand assets

| File | Use |
| --- | --- |
| `hark-wordmark-white.svg` / `hark-wordmark-black.svg` | Wordmark on dark / light backgrounds (transparent) |
| `hark-icon.svg` | App icon (source of `hark_addon/icon.png`, 128×128) |
| `hark-logo.svg` | Wordmark on a dark tile (source of `hark_addon/logo.png`, 250×100) |
| `social-preview.png` | GitHub social preview (1280×640, Settings → General → Social preview) |

The wordmark is set in [Outfit](https://fonts.google.com/specimen/Outfit) Bold (SIL Open Font
License 1.1) and converted to outlines, so no font file is needed. The "a" is a custom glyph:
an open ring around a dot, Hark listening.

Keep the mark white on near-black (`#0B0B0D`) or black on white; no gradients, glows or
recolouring.
